# Contributing to UHC ELOUD

UHC ELOUD is developed and maintained by one person. Bug reports and ideas from players and server owners are very welcome; they decide what goes into each version.

You can write in English or Spanish.

## Report a bug

1. Search the [existing issues](https://github.com/Dalibex/eloud-uhc/issues) first.
2. Open a [bug report](https://github.com/Dalibex/eloud-uhc/issues/new?template=bug_report.yml).
3. Include the versions of the plugin, the server and the required plugins, the steps to reproduce and the console error if there is one.

## Suggest an idea

Open an [idea or suggestion](https://github.com/Dalibex/eloud-uhc/issues/new?template=feature_request.yml). Explain the problem it solves in a match, not only the feature.

## Ask a question

Use [Discussions](https://github.com/Dalibex/eloud-uhc/discussions/categories/q-a) for help with installing, configuring or hosting a match.

## Report a security problem

Do not open a public issue. Follow [SECURITY.md](SECURITY.md).

## Code contributions

Pull requests from outside the project are not accepted. The plugin is licensed under the [PolyForm Noncommercial License 1.0.0](LICENSE), and the maintainer keeps full control over its code and licensing. If you found a fix, describe it in an issue.
