# Security policy

## Supported versions

Only the latest release receives security fixes.

| Version | Supported |
| --- | --- |
| Latest release | Yes |
| Older releases | No |

## Report a vulnerability

Do not open a public issue for security problems.

Report it privately from the [Security tab](https://github.com/Dalibex/eloud-uhc/security) with **Report a vulnerability**. Include:

- What the problem is and its impact on a server or its players.
- Steps to reproduce it.
- The versions of the plugin, the server and the required plugins.

The report stays private between you and the maintainer until a fix is released.

Problems in the server software or in other plugins should be reported to those projects.
